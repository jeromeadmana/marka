## 🆘 Getting Help

### When You're Stuck

1. **Check the docs** - Most answers are in QUICK_START or WEEK_01_CHECKLIST
2. **Ask Claude Code** - I'm here to help! Just describe the issue
3. **Google the error** - Stack Overflow is your friend
4. **Take a break** - Sometimes stepping away helps

### Common Issues

**"dotnet: command not found"**
→ .NET SDK not installed or not in PATH

**"Can't connect to Aiven"**
→ Check firewall, verify SSL Mode=Require

**"npm install fails"**
→ Make sure Node.js 20+ is installed, try clearing cache

**"Git push rejected"**
→ Authenticate to GitHub, check remote URL
